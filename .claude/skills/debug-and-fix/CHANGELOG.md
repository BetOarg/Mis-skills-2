# Changelog — debug-and-fix

## 1.0.0 — Initial version
- Added evidence-first diagnosis and minimal-change workflow.
- Required regression coverage, diff inspection, and final-state verification.
- Defined VERDE / ROJO / PENDIENTE / BLOQUEADO reporting.

- Added red-capable reproduction, minimization, falsifiable hypotheses, vertical-slice TDD, independent oracles, and secret redaction guidance.
